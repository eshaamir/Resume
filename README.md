<h1>Esha Amir's Resume</h1>
<p>This is a React-based web application showcasing the professional resume of Esha Amir. The app displays education, technical skills, projects, and professional experience in a clean and structured format.</p>

<h2>Features</h2>
Responsive Design: The resume layout is responsive and adapts to different screen sizes.
React.js: Built using React.js to create a dynamic and interactive web experience.
Live Links: Contains live links to projects, LinkedIn, and GitHub profiles.
Clean UI: Minimalist and professional design to present information clearly.
